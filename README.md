## Agent contract

`agent(obs_dict) -> list[int]`. On the first call (`obs["select"] is None`) the
agent returns its 60-card deck; thereafter it returns indices into
`obs["select"]["option"]`. The agent must never crash and must always return a
legal move, so every pilot falls back: deck-specific layer -> generic heuristic
-> first legal option.

## Reproducing the arena numbers

```
python arena.py --agent ogerpon_heuristic \
                --deck ../meta/top_decks/deck_ogerpon_ours.csv \
                --reps 5 --games 60
```

Requires the competition's `cg` package on the path. Note the caveat from the
writeup: arena **absolute** win rates are optimistic because we pilot the
opponents ourselves. Use it for relative comparison and matchup discovery only.
